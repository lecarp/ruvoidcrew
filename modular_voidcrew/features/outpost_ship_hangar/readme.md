# Outpost Ship Hangar (Ангар кораблей на торговых аванпостах)

## Описание
Модульная система долговременного хранения, сохранения физического состояния судна и инвентаря (DMM-слепки) и смены кораблей на торговых аванпостах с сохранением между раундами.

## Компоненты
* `icons/hangar_console.dmi` — спрайт янтарного экрана консоли ангара `[H]`.
* `code/hangar_defines.dm` — константы путей (`data/player_saves/[ckey[1]]/[ckey]/ships/`), статусы слотов.
* `code/hangar_manager.dm` — атомарная сериализация карт DMM через `write_map()`, экспорт содержимого ящиков и шкафов, эвакуация экипажа, загрузка через `SSshuttle.action_load()`.
* `code/hangar_console.dm` — терминал `/obj/machinery/computer/outpost_ship_hangar` с интерфейсом TGUI в стиле Helm.

## Точки спавна (снаружи лифта)
* **В ангаре причала:** на посадочной палубе прямо между входными шлюзами, ведущими к лифту (снаружи кабины, лицом к кораблю).
* **В вестибюле (Concourse, этаж 0):** в главном зале у входа в лифт (снаружи кабины лифта), чтобы игрок без корабля мог заказать борт прямо из торгового зала.
